# 网页答题助手

书签小工具（Bookmarklet）。点一下书签，自动识别当前网页里的题目，调大模型接口，在悬浮面板里显示【答案】【解析】。

零安装：不需要浏览器扩展，不需要 Tampermonkey，不需要本地服务，不打包。

## 安装

**方式 A（推荐，有图形界面）**

1. 用浏览器打开本目录下的 `install.html`（双击即可）。
2. 显示书签栏：`Ctrl+Shift+B`（Mac `⌘+Shift+B`）。
3. 把页面里的「答题助手」按钮拖到书签栏。

**方式 B（手动）**

1. 用记事本打开 `bookmarklet.txt`，全选复制（是一行很长的 `javascript:` 代码）。
2. 在书签栏右键 → 添加网页 → 名称填 `答题助手`，网址粘贴刚才的内容。

## 配置

配置**写在书签里**，所以换任何网站都不用再填。

在 `install.html` 里填三项，页面会实时重新生成书签：

| 项 | 示例 |
|---|---|
| 接口地址 | `https://api.deepseek.com/v1` |
| 模型 | `deepseek-chat` |
| API Key | `sk-...` |

勾选「把 API Key 一并写进书签」后，配置随书签走，全站通用；不勾选则每个网站首次使用时在面板里填一次。

为什么之前会"每个站都要配"：旧版把配置存在 `localStorage`，而 `localStorage` 按网站（同源）隔离，A 站存的 Key B 站读不到。写进书签后没有这个问题。

> 明文风险：书签是明文保存的。浏览器开了账号同步，书签会同步到云端；共用电脑时别人也能看到。好处是目标网站的页面脚本读不到这个 Key（比存网站 localStorage 更安全）。不想写进去就取消勾选。

面板里仍保留「设置」，改的是当前站点的 `localStorage` 覆盖值，不影响书签里的配置。

## 使用

- 点击书签栏「答题助手」→ 自动抓取视口中央的题目 → 显示答案。
- 面板显示：题型标签、题干、**答案字母卡**、**选项列表（正确项高亮）**、置信度徽章（高绿/中橙/低红）、可折叠解析。
- 面板标题栏可拖动，拖动后的位置会记住，下次点开还在原处。
- `重新抓题` 强制重新识别并请求，`复制` 按【答案】/【解析】/【置信度】格式复制，`设置` 改配置。
- 再点一次书签 = 折叠/展开面板，不会重复请求。
- 如果一个页面有多道题，先**选中那道题的文本**再点书签，会优先用选区。

### 刷新页面之后

刷新后助手会消失，需要再点一次书签。这是浏览器的安全模型决定的：书签脚本只能在你点击的那一刻运行，页面刷新会销毁它。零安装方案做不到常驻。

为了把这一步的成本降到最低：

- 点一下书签，**上次的答案会立刻恢复**（从本机缓存读取，不用等接口）；如果当前题目和上次是同一道，直接显示，不再请求。
- 键盘路径：把「答题助手」拖到书签栏**最左边第一格**，刷新后按 `Alt+Shift+B` 聚焦书签栏，再按 `Enter`，全程不用鼠标。

## 更新脚本后要重新安装

`src/main.js` 改动并重新 `node build.mjs` 之后，书签里存的还是旧代码，必须**删掉旧书签，重新拖一次安装按钮**才会生效。

## 支持的题型

| 题型 | 识别依据 | 面板输出 |
|---|---|---|
| 单选 | 有 A/B/C/D 选项，题干无「多选」字样 | 大字母 + 对应选项高亮 |
| 多选 | 有选项且题干含「多选 / 不定项 / 选出所有 / 全部正确」 | 多个字母 + 多项同时高亮 |
| 判断 | 选项是「正确 / 错误」，或无选项但含判断词 | 字母或判定词 |
| 填空 | 含 `____`、`（ ）` 且无选项 | 填空内容，多个空用 `|` 分隔 |
| 简答 | 无选项，含「试述 / 简述 / 说明 / 分析 / 区别 / 如何」等问法 | 分点作答的文本块（可滚动） |
| 编程 | 含【问题描述】【样例输出】评分标准、主类名、`class X {` | 深色代码块 + 「复制」按钮 + 思路 |

编程题会额外读取页面编辑器里已有的代码（`textarea` / CodeMirror / Monaco / `contenteditable`）作为上下文一起发给模型，让结果贴合题目给定的模板结构。

## 自动识别的逻辑

三级回退，全部无需手动操作：

1. 页面有选中文本 → 用选区；
2. 否则在**视口左侧与中心多点采样**（适配“左题右答”的分栏布局），向上找特征最强的文本块，并跳过 `textarea`、`contenteditable`、代码编辑区等作答区；
3. 还不行就全页扫描，取特征最强的小块。

采样后先过滤导航噪音（“返回 / 题目列表 / 下一道题 / 提交 / 控制台”等整行），再按题型切出题干与选项。

评分同时看选项密度与题干标记（`【问题描述】`、`【样例输出】`、`试述/简述`、`class Main`），所以选择题、简答题、编程题都能命中。

## 已知限制

- **CSP 严格的站点会失败**：bookmarklet 运行在页面上下文，受页面 CSP 约束。如果提示「请求被拦截」，是 `connect-src` 或接口 CORS 的问题，这类站点只能改用油猴脚本（`GM_xmlhttpRequest` 不受限）。
- **接口必须支持浏览器直连（CORS）**：DeepSeek、OpenAI 及多数 OpenAI 兼容接口都支持；自建服务需自行加 `Access-Control-Allow-Origin`。
- **图片题不支持**：没有 OCR，需要题目是文字。
- **答案不保证正确**：模型会幻觉，专业题尤其。面板里给了「置信度」，不确定时会写「不确定」。
- **编程题会把编辑器里已有的代码发给模型**（用于补全），不要在含隐私代码的页面使用。
- **简答/编程答案偏长**：面板内滚动查看，点「复制」可取全文。
- **不自动提交**：只展示，不点击、不填答题框。
- `chrome://`、扩展商店、PDF 阅读器等特殊页面无法运行书签脚本。

## 开发

```bash
node build.mjs     # 由 src/main.js 生成 bookmarklet.txt 和 install.html
node --check src/main.js
```

改完 `src/main.js` 重新执行 `node build.mjs`，再重新安装一次书签即可。
